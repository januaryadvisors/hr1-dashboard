# Texas SNAP & H.R. 1 dashboard: front-end build spec

This document specifies the Map page shown in wireframe 1a - DASHBOARD, the Insights page, and the provisional Districts view. It exists so the build does not re-decide anything Feeding Texas has already settled and does not design against a data shape the scored file cannot support.

| Deliverable | D1 county vulnerability dashboard, public web |
|---|---|
| Primary audience | Policy and legislative staff. Food-bank program staff second. |
| Binding inputs | dashboard-map-design.md §2–§5 · requirements.md · the attached wireframe · this spec |
| Design system | January Advisors, "Seriously Practical". Navy #004E7B, teal #00B9C3, orange #FAA634, ink #262626, warm grey #F0EDED. |

Read before writing code. §11 lists options already rejected with reasons. Do not propose or build any of them. §10 lists framing rules from the client that constrain what may appear on a map at all. Both are client decisions, not preferences.

## 1. Scope

### In scope

Map page — hero, time-window brush, six layer maps in three render styles, assistance-infrastructure overlay, right rail, three summary charts.

- Insights page — five tabbed chapters, thirteen charts (§8).

- Districts view — TX House and TX Senate only, shipped behind a provisional banner (§9).

- CSV/JSON download of whatever the current filter state selects.

- Responsive down to 1024px. Below that, the map panel goes full-width and the right rail stacks underneath.

### Out of scope for this build

- US House districts. The plan is unchosen, so the crosswalk does not exist.

- The healthcare-access section. Requirement F10 keeps it separate from the SNAP index; it is its own surface.

- School-meals layer. Still an open presentation choice.

- Any authenticated or write surface. The dashboard is read-only.

- Dark mode in v1. Tokens should be authored as CSS custom properties so it can be added; D1's navy #0E3464 fails on a dark ground and needs the lightened ramp noted in §12.

## 2. Stack

Keep it small. This is a static site with no backend.

| Concern | Choice | Why |
|---|---|---|
| Framework | React 18 + Vite, TypeScript | Single-page, no SSR needed. Static build to S3/Pages. |
| Routing | react-router, three routes | /map, /insights/:tab, /districts. |
| State | useReducer + one context, mirrored to URL query params | No Redux, no Zustand. The whole app state is roughly nine fields (§4). URL mirroring makes every view shareable, which policy staff will use. |
| Maps | Inline SVG, hand-rendered from TopoJSON | 254 paths per panel performs fine and was proven in the prototype. No Leaflet, no MapLibre — Leaflet is one-map-at-a-time and cannot do synced small multiples. |
| Projection | d3-geo geoAlbers tuned to EPSG:3083 | Texas Albers. Fit once to the state bbox and reuse the same projection object across every panel so thumbnails and the hero map register exactly. |
| Charts | d3-scale + d3-shape, rendered as JSX SVG | No chart library. Every chart in §8 is a line, column, dumbbell, scatter or small-multiple — all trivial as JSX. Avoids fighting a library's defaults for the axis and annotation treatments this design needs. |
| Data loading | Static JSON fetched once, cached in context | Total payload target under 900KB gzipped including geometry. |
| Styling | CSS modules + custom properties for tokens | No Tailwind. Token values come from the JA system. |
| Testing | Vitest for the scale/binning/format helpers only | Those are where a silent error changes what the map claims. Do not unit-test presentational components. |

## 3. Data contract

The front end reads four static files from /data/. rscripts/export_tool_data.R is unwritten, so these shapes are the contract the export must satisfy. Do not read vulnerability_county.csv directly in production — build against these.

Layer five has no source. The wireframe adds a Children layer to the four scored domains. There is no d5_* column in vulnerability_county.csv. Either it is defined and added to build_scores.R before the build, or the layer strip ships with five entries. Do not synthesize it from the SNAP age bands — those are statewide, not county-level.

## 4. State model

One reducer. Every field is mirrored to a query param so any view is a link.

| Field | Values | Effect |
|---|---|---|
| measure | rate | count | Global. Switches every map and the layer thumbnails between percentile fill and proportional symbol. |
| layer | d1…d5 | composite | Which layer the hero map shows. |
| style | geo | grid | density | Render mode for the hero map (§6.5). |
| window | [startMonth, endMonth] | Set by the brush. Everything below the brush recomputes: the hero number, the map's decline values, all three summary charts. |
| infra | Set of 4 keys | Which infrastructure marks draw on the map. |
| overlayQ5 | boolean | Outlines every county in Q5 on the showing layer. |
| overlayGap | boolean | Outlines gap counties in red. |
| hovered | geoid | null | Transient. Not in the URL. |
| pinned | geoid | null | Survives cursor movement. In the URL. |

hovered ?? pinned is the county every readout reads from. One selector, used everywhere.

## 6. Map page

### 6.1 Hero band M-01

Two columns, roughly 68/32, on warm grey.

- Eyebrow: the active window, e.g. JUL 2025 → MAY 2026, Borna caps 10px, tracked.

- Headline number: −547,051 at 76px Mulish 800 in burgundy #B44A3F, tabular-nums, set on the same baseline as a 22px Onest phrase: "fewer Texans on SNAP than the month H.R. 1 was signed". The number recomputes from the brush window; the phrase after it changes with the window's start.

- Body: two to three sentences, Onest 16px, max 62ch. Not lorem — the copy states the delayed onset, the November drop near 110,000, and the flat 70–80k monthly pace since.

- Download data: secondary pill button, navy outline. Exports the current window and layer selection as CSV, with a companion JSON that includes the MOE columns.

### 6.2 Time-window brush M-02

Full-width card under the hero. A 44-month enrollment line, y-axis 2.9M to 3.7M, x-axis 2021 to 2026. The selected window is a burgundy-tinted band with draggable handles at both edges; inside the band the line is drawn in burgundy, outside in muted navy. Endpoint labels sit above the handles.

- Instruction text, always visible: "Drag either handle. Everything below follows this window."

- Four presets, right-aligned: Since H.R. 1 (default), Last 6 months, Last 12 months, Full history.

- Debounce the drag at 120ms before recomputing dependents. Handles have a 24px hit area and respond to arrow keys when focused, one month per press.

- This is the only time control in the app. There is no separate month slider on the map.

### 6.3 Statement rail M-03

Right of the hero, separated by a vertical hairline. Three fixed statements, each a large figure over two lines of Onest. These are statewide narrative points and never become county metrics.

| Figure | Statement |
|---|---|
| −19.1% | among adults 18–59, the steepest band. Ages 65+ are flat at −0.2%. |
| −22.6% | excess decline once each county's own pre-policy trend is netted out. |
| 9.3% | of Texans are enrolled, down from 11.0% in July 2025. |

### 6.5 Hero map panel M-05

Panel header carries the layer's formal name ("D1 — Work-requirement exposure"), two to three sentences of layer-specific copy, the component count, and a right-aligned Style segmented control plus the legend. Three render styles, all reading the same data:

| Style | Chart type | Spec |
|---|---|---|
| Geo | Choropleth | True county polygons, Texas Albers. Fill from the layer ramp at the county's percentile. White 0.5px strokes, state outline at 1px navy. Default style. In count measure this becomes a proportional-symbol map over a neutral base — never a fill of raw counts. |
| Grid | Cartogram | One equal-size square per county on the precomputed grid lattice, roughly 22×24 cells. Every county gets identical visual weight, which is the honest reading of a percentile: Loving and Harris are one square each. Same ramp, same legend. Region labels on hover only. |
| Density | Bubble map | Circles at county centroids over a light county outline. Radius is square-root-scaled on the count metric (or on population in rate measure), fill is the layer ramp at percentile. This is the one view that carries magnitude and rate at once. Sort descending by radius when painting so small circles land on top; nudge overlapping metros apart with two passes of simple collision relaxation, no force simulation. |

Legend sits top-right of the panel: a continuous ramp bar labelled PERCENTILE IN TEXAS, p0 to p100. In count measure it becomes three nested circles with real values.

#### Interaction

- Hover highlights the county in the hero map and in all six layer thumbnails simultaneously. This synced highlight is the mechanism that makes the domain disagreement legible; without it the strip is just six pictures.

- Click pins. Pinned county gets a persistent 1.5px ink outline and the readout holds.

- Tooltip on hover: name, population, all layer percentiles with their tiers, cumulative impact, the count metric if the layer has one, MOE, and infrastructure presence. Follows the cursor with a 12px offset, flips at the viewport edge.

- Keyboard: the map is a single focusable group; arrow keys walk counties in reading order on the grid lattice, Enter pins. Every county path carries an aria-label.

- Counties with small_denominator render at 0.4 opacity in rate measure, with a footnote naming the guard.

## 8. Insights page

Five tabs in a left column, one chapter each. Each chapter opens with a one-sentence claim in Mulish, then its charts, then a "what this does not support" line. The Rate/Count control stays visible but is inert on tabs where it does not apply — label it so.

### Tab 1 — The decline has not stopped

Claim: enrollment is still falling, and the pace is flat rather than slowing.

- Enrollment line, 2022 → May 2026. Peak marked at 3,654,101 (Jan 2023); H.R. 1 band from July 2025; endpoint labelled 2,971,598. Pre-window in muted navy, policy window in burgundy.

- Monthly-change columns. Same data as M-10 but full width, with every month labelled and the November −110k and May −78,861 called out.

- Participation share. Single line, 11.0% → 9.3% of Texans enrolled, with a light band for the 2023 peak.

Does not support: causal attribution to H.R. 1. Emergency-allotment expiry and the Medicaid unwinding overlap this window.

### Tab 2 — Who is falling off

Claim: working-age adults and children carry the entire decline; seniors are unchanged.

- Age-band indexed lines. Five lines, indexed to 100 at July 2025, monthly to May 2026. 65+ runs flat along the top; 18–59 drops furthest.

- Age table. Band, July 2025 enrolled, latest enrolled, change, percent change. The −19.1% / −0.2% spread is the finding.

- People vs. households, indexed. Two lines: people −15.5%, households −13.6%. The gap says households are shrinking as well as exiting.

### Tab 3 — The four domains disagree

Claim: no single ranking of counties can be honest about all four exposures.

- Small multiples. Four maps at equal size with synced hover, reusing . Style control applies to all four at once.

- Correlation matrix. 4×4 heat grid. Diverging navy-to-burgundy, values printed. The −0.30 D1/D2 cell and the 0.43 maximum are annotated.

- Cumulative-impact distribution. Column chart of the 113 / 91 / 38 / 11 / 1 split, with the note that this is why cumulative impact is an outline and not a fill.

### Tab 4 — Where exposure meets thin capacity

Claim: the counties with the least enrollment help are not the ones with the most.

- Gap scatter, full width, the M-10 chart with a labelled county list beside it.

- Infrastructure coverage bars. Four horizontal bars, counties covered out of 254, per registry type.

- Gap-county table. Name, vulnerability percentile, sites by type, population.

This tab is the weakest half of the project. Feeding Texas still owes food-bank enrollment FTE and households-reached by county. Ship the tab with a standing banner saying capacity is a floor, not a measure, and that requirement F4 cannot be answered from navigator counts alone.

### Tab 5 — Rate and count are two arguments

Claim: targeting by rate and targeting by count select different counties, and both are legitimate.

- Paired maps. Percent-decline choropleth beside a proportional-symbol count map, same window.

- Top-10 absolute losses. Bar chart: Harris 109,917 down to Montgomery 8,749, with the note that these ten hold 62% of the statewide drop.

- Funnel plot. Percent change against caseload with control limits; roughly 93% of counties sit inside, and the ones outside are all tiny — Loving on eight, Borden on seventy. A shrinkage toggle switches raw against stabilized values.

County-type rollup as a footer stat: metro −15.6%, micro −14.9%, rural −15.8%. The contraction is broad and even.

## 9. Districts view — provisional

Ship it behind a persistent amber banner reading "Provisional — aggregation method not settled." TX House (PlanH2316, 150 districts) and TX Senate (PlanS2168, 31) only; the US House control is present but disabled with a tooltip naming the blocker.

The aggregation is a back-end change, not a front-end one. Percentile scores cannot be population-weighted into districts and stay meaningful. Districts must be re-ranked from the underlying rates through the block-weighted crosswalk, then percentiled within the 150 or 31 district set. Do not compute district scores in the browser.

Layout mirrors the Map page: the same layer strip, the same map component fed district geometry, a rank table replacing the county tooltip. Newly-subject count is the lead column, since it is the figure a legislative office asks for.

## 10. Copy and framing rules

These come from Feeding Texas. They constrain content, not just tone.

- No single "total impacted" number. Layered hotspots instead. The hero number is observed enrollment change, not a modelled impact estimate, and the copy must keep that distinction.

- Descriptive only. Exposure and at-risk framing. Never causal claims, never precise loss counts.

- "SNAP families with no workers" may not appear as a vulnerability indicator. Those households are typically exemption-protected and the frame invites "why aren't these people working." Lead from the work-requirement-subject population.

- Cost-share and payment error rate stay statewide narrative points — 9.34% in FY2025, up from 8.32%, inside the 10% match tier. Never a county metric, never mapped.

- Handle the rural SNAP-retailer decline carefully. Do not feed a "SNAP won't help rural areas anyway" reading.

- Flag synthetic estimates. ABAWD exposure is PUMS-modelled, not a lookup, and says so wherever it appears.

- Every estimate ships with its MOE. In the tooltip, in the download, in the table.

- Three policy levers stay separable in both index and narrative. Never blended.

- Voice: first-person plural, Title Case for display and UI labels, sentence case for body. One capsule highlight per headline, on the single most important word, at 50% opacity with circular edges.

## 11. Rejected options

Recorded so they are not proposed again. Each was ruled out on evidence, not taste.

| Option | Why it is out |
|---|---|
| Dominant-domain map | Domains "win" 71 / 75 / 44 / 64 counties — a near-even four-way split — and the median margin between first and second is 0.105, with a quarter of counties under 0.044. It would colour Texas on noise. |
| Bivariate hue-and-intensity map | Inherits the dominant-domain problem and adds a harder encoding on top. |
| Blended composite as the headline | Publishing the sub-scores is the point of the framework. The composite also reads as a border map: the top twelve counties are all border or South Texas and all score ≥ 0.71 on D2, so the one domain telling a non-border story gets averaged away. |
| Choropleth of raw counts | Harris at 5.13M residents swamps any fill scale. Counts use proportional symbols or the cartogram. |
| A 1-to-254 ranked list | Ruled out by requirement F9 at kickoff. |
| Leaflet or any tile-map library | One map at a time. Small multiples with synced hover are the default view, so the map must be inline SVG. |

## 13. Suggested build order

- Fixture data matching §3, plus the projection and binning helpers with their unit tests.

- in all three styles at thumbnail and hero size. This is the whole risk of the project; get it right before any chrome.

- State reducer and URL mirroring.

- Map page composition: layer strip, hero panel, right rail.

- Brush chart and the recompute path down to the three summary cards.

- Infrastructure marks and the two overlays.

- Insights tabs 1, 2, 5 (statewide data, already available), then 3, then 4.

- Districts empty-state, then the real view when the file lands.

- Accessibility pass: keyboard map navigation, focus rings, contrast on every ramp's mid stop, and a text-alternative table behind each map.

One thing to check before you start. The domain ramps in §6.4 must match rscripts/build_scores.R:317–325 character for character. If the internal leaflet review maps and the dashboard disagree on colour, every conversation about the data turns into a conversation about the tool.
